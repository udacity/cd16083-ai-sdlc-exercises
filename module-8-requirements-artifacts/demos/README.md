# Demo files: Evaluate AI-Generated Requirements Artifacts

The files shown in this module's two demo videos. Both demos use Atlas, an online tutoring marketplace. The prompts pasted into Claude Code are in `demo-prompts.md`.

| Demo | Folder | Files |
|---|---|---|
| The stories that read well and failed | `the-stories-that-read-well-and-failed/` | The requirements checklist, the request and the prompt, the stories the AI returned, and the team brief the prompt never included |
| Writing the rules before the AI writes the stories | `writing-the-rules-before-the-stories/` | The rules, the team brief, the first set of stories (checked for contradictions), and the requirements checklist |
