# User stories: online appointment booking at Cedar Clinic

Prepared by the practice manager for the vendor. The stories were generated by an AI assistant and
selected by hand. The vendor's analyst received this file as "the requirements".

A **user story** is one sentence of what a user needs and why, in the form "As a …, I want …, so
that …". **Acceptance criteria** are the checkable conditions a story must meet to count as done.

---

**Story 1.** As a patient, I want to create an account with my email address, so that I can book
appointments online.

- Email address is verified before the account is activated.
- Duplicate accounts are rejected.

**Story 2.** As a patient, I want to search for open slots by provider, location, and date, so that I
can find a time that suits me.

- Only slots that are open right now are shown.
- The three filters can be combined.

**Story 3.** As a patient, I want to select a slot and confirm my booking, so that my time is
reserved.

**Story 4.** As a patient, I want to cancel an appointment at any time, so that the slot can be
released for others.

- A cancelled slot is returned to availability.
- The patient receives a cancellation confirmation by email.

**Story 5.** As a patient, I want to describe my reason for the visit when I book, so that the
provider can prepare.

- The reason is free text, up to 200 characters.
- The reason is shown on the patient's confirmation screen and in the confirmation email.

**Story 6.** As the clinic, we need patient data encrypted with AES-256 in line with HIPAA, so that
it is legally protected.

- Data is encrypted in transit and at rest.

**Story 7.** As an administrator, I want to set a cancellation window, so that the clinic's policy is
enforced automatically.

- The window is 24 hours.
- A cancellation inside the window is refused by the system.

**Story 8.** As an administrator, I want to set each provider's bookable hours at each location, so
that patients can book only inside them.

- Hours are set separately per provider per location.
- After a change, patients see only slots inside the new hours.
